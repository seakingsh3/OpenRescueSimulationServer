🔒 HTTPS
…

Mikrofon (Durchsagen) und manche Tablet-Funktionen gibt der Browser nur über HTTPS frei. Der Server nutzt dafür eine eigene, lokale Zertifizierungsstelle; ihr Wurzelzertifikat wird einmal auf jedem Ausbilder-Gerät installiert.

Wurzelzertifikat für iPads und PCs

Noch kein Wurzelzertifikat – zuerst HTTPS einrichten.
⬇️ Wurzelzertifikat herunterladen
  • iPad/iPhone: QR-Code scannen → Profil laden → Einstellungen → „Profil geladen“ → Installieren. Danach Allgemein → Info → Zertifikatsvertrauen einschalten.
  • Windows: Datei öffnen → Zertifikat installieren → Lokaler Computer → „Vertrauenswürdige Stammzertifizierungsstellen“.
  • Android: Einstellungen → Sicherheit → Verschlüsselung → Zertifikat installieren → CA-Zertifikat.

Einrichten / Zertifikat erneuern

Der Server startet danach neu (laufende Sessions werden unterbrochen). Das Serverzertifikat gilt 825 Tage; das Wurzelzertifikat bleibt beim Erneuern gleich, Geräte müssen es nicht neu installieren.
